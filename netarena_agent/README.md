# One Jump NetArena MALT Agent

This is a deterministic participant for the public
[NetArena MALT benchmark](https://agentbeats.dev/agentbeater/netarena-malt-policy-benchmark).
It compiles the benchmark's controlled English into the five graph helpers exposed
by the evaluator. It uses no task IDs, answer table, model API, or benchmark seed.

The response separates two channels:

- `data` is the requested computation or hypothetical graph result.
- `updated_graph` is the state safe to apply under NetArena's hierarchy,
  connectivity, and bandwidth checks.

This matters when a generated request itself would create an invalid hierarchy or
orphan nodes. The requested result remains inspectable, while an unsafe mutation
is not committed.

## Verify

Run the unit suite:

```bash
python -m pytest tests/test_netarena_agent.py -q
```

Run against a clean checkout of the official evaluator (250 queries per each of
10 templates = 2,500 total):

```bash
uv run --isolated --no-project \
  --with-requirements netarena_agent/requirements-validation.txt \
  python tools/run_netarena_malt_validation.py \
  --netarena-repo /path/to/NetArena \
  --num-each-type 250 \
  --seed 20260920
```

## Attribution

The direct compiler design was independently checked against the public,
MIT-licensed MALT adapter in
[AegisForge](https://github.com/ivanjojo369/AegisForge_agent), whose published
AgentBeats run demonstrated that deterministic parsing can scale to 2,500
regenerated queries. This implementation is intentionally small and scoped only
to the query grammar generated by NetArena.
